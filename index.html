Cifra de César

A Cifra de César é uma técnica de criptografia que substitui cada letra por outra, deslocando sua posição no alfabeto.

Passo 3 - Como funciona?

Para cifrar: somamos a chave à posição de cada letra.

Para decifrar: subtraímos a chave da posição de cada letra.

Utilizamos o operador % 26 para manter as letras dentro do alfabeto.

Desafio Final

Se uma mensagem foi criptografada com a chave 3, devemos subtrair 3 da posição de cada letra para recuperar o texto original.
